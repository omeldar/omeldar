### what I build

**Minecraft mods, more than is strictly reasonable.** A [caretaker](https://github.com/omeldar/goh-keeper)
that finds where the lag is and keeps backups that actually restore. A
[world border](https://github.com/omeldar/goh-worldgrow) that grows without the stutter. An
[autopilot](https://github.com/omeldar/goh-autopilot) that records your farm run once and replays
it while you go do something else. And [Lumi](https://github.com/omeldar/lumi), a helper who lives
in the game and answers through Claude. Fabric and Java, all of it written because the thing I
wanted didn't exist yet.

**Things that draw.** [Procedural and rule-based texture synthesis](https://github.com/omeldar/baa-algorithmic-texture-synthesis),
a [raytracer](https://github.com/omeldar/raytracer), an
[interactive viewer](https://github.com/omeldar/3d-matrices-viewer) for camera transforms and
rotation matrices. Graphics is the one corner of this field where you can tell at a glance whether
you got it right.

**Small tools nobody asked for.** A [launcher](https://github.com/omeldar/ig_reels_launcher) whose
entire job is opening Instagram Reels from Steam. Scripts that automate anything I'd otherwise do
twice. Config kept in version control so a fresh machine is one `git clone` away.

**Puzzles, in languages that make them harder.** [Advent of Code](https://github.com/omeldar/adventofcode)
in Haskell, every December, against my better judgement. Randomized algorithms, graph algorithms,
and the occasional proof that something actually terminates.

### how it usually goes

Something annoys me → I decide it'll take an afternoon → it takes a fortnight → it works → I write
a README nobody reads. Repeat.

Mostly Java and TypeScript. Haskell when I want to feel something, Python when I want it done by
lunch.
